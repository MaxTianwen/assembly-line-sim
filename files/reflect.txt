	2) There should be a loop to read the tokens until EOF, extracting all the items.

	1) In order to find the first Workstation, we need to use a nested loop to look for the Workstation so that no pointers point to it.
	2) Since the copy constructor and copy assignment operator are prohibited, it is necessary to use std::move() to convert objects to the right values when passing to functions.
